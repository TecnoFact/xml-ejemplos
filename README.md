Este repositorio contiene ejemplos de archivos XML CFDI (Comprobante Fiscal Digital por Internet) para facturación electrónica en México.

**Tipos de CFDI Incluidos:**
*   Factura (Ingreso)
*   Nota de Crédito (Egreso)
*   Recibo Electrónico de Pago
*   Carta Porte
*   (Se pueden añadir más tipos según el contenido del repositorio)

**Estructura del Repositorio:**
Los archivos XML CFDI de ejemplo están organizados por tipo de comprobante en carpetas separadas para facilitar su consulta.

**Tecnologías y Estándares Relacionados:**
*   Anexo 20 de la Resolución Miscelánea Fiscal (RMF): Especificaciones técnicas del CFDI.
*   Anexo 24 de la RMF: Catálogos del CFDI.
*   (Se pueden añadir otros estándares o tecnologías relevantes si aplica).

**Instrucciones de Uso:**
Estos ejemplos de XML CFDI pueden ser utilizados para:
*   Probar la funcionalidad de sistemas de facturación electrónica.
*   Como referencia para la generación de comprobantes fiscales digitales.
*   Entender la estructura y los campos requeridos para cada tipo de CFDI.

Este repositorio está destinado a servir como referencia o punto de partida para desarrolladores que necesiten generar o procesar facturas electrónicas en México.
